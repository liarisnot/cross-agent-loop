# Plan: sandbox-env

Build sandbox-env as designed in docs/designs/sandbox-env.md, in the design's five phases: the Sandbox.psm1 seam (environment grants and variables, the lock helper, Invoke-SandboxCommand), SandboxEnv.psm1's read side (discovery, identity hash, status, estimate, report) and write side (build, prune, rebuild, readiness gate, link and unlink), the delegate.ps1 surface (-SandboxEnv, -SandboxRun, the worker launch gate and cleanup unlinking), then doctor and the skill text. Every task follows the design's Rules and Files sections; task files point workers at the exact rules. Tasks that edit the same file run one after another. No step needs the user, other than having uv on the host and the private repo for the live checks at sign-off.

Check-in mode: on-problems
