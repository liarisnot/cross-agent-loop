# Plan: sandbox-env

Build sandbox-env as designed in docs/designs/sandbox-env.md, in the design's five phases: the Sandbox.psm1 seam, SandboxEnv.psm1's read side and write side, the delegate.ps1 surface, then doctor and the skill text. Each brief names the functions and shapes other tasks rely on; the design's Rules and Data sections give the behaviour. Tasks that edit the same file run one after another. Profile is the delegate worker profile (models.json). Not tasks: the design's live checks (Verification 1-8, which need uv on the host and the private repo) and the docs/test-plan.md and docs/HANDOFF.md updates are done by the lead at sign-off.

Check-in mode: on-problems
